Tất cả công cụ bạn cần để xử lý tài liệu

Từ OCR, dịch thuật, chau chuốt đến tạo sách multimedia — DeepTransAI làm tất cả tự động với AI.

📋

Quản lý dự án

Tạo, chỉnh sửa, xem chi tiết và xóa dự án. Mỗi dự án lưu đầy đủ thông tin: tên, thể loại, file nguồn, thư mục lưu, trạng thái, tiến trình. Hỗ trợ phân trang và tìm kiếm.

CRUD SQLite Pagination Real-time
🔍

OCR — Nhận dạng văn bản

Chuyển PDF thành ảnh, dùng Vision AI (Gemini) nhận dạng văn bản từng trang. Xử lý song song 5 trang, lưu kết quả thành file DOCX riêng lẻ cho mỗi trang.

Vision API Parallel 5x PDF → Text
🌐

Dịch thuật AI với Context

Dịch từng segment bằng AI, gửi kèm 2 đoạn đã dịch trước làm context để giữ nhất quán giọng văn, xưng hô, tên riêng. Hỗ trợ custom System & User Prompt.

Context-aware Custom Prompt Auto-resume
✏️

Chau chuốt bản dịch

Sau khi dịch, AI tự động chau chuốt — so sánh với bản gốc để đảm bảo câu từ mượt mà, tự nhiên, đúng nghĩa. Xử lý đa luồng (5 threads).

Multi-thread 5x Auto Polish Gốc → Dịch → Edit
📖

Xem & Chỉnh sửa kết quả

Giao diện 3 cột song song: Bản gốc | Bản dịch | Bản chau chuốt. Chỉnh sửa trực tiếp, lưu JSON, export DOCX. Hỗ trợ điều hướng nhanh.

3-column View Edit & Save Export DOCX
📚

Tạo sách Multimedia lật trang

Tạo sách lật trang HTML từ PDF: render ảnh, thumbnail, trích xuất text & vị trí cho tìm kiếm, chèn meta tags. Hỗ trợ tích hợp audio từng trang.

Flipbook HTML Search Text Audio
🔊

Audio Editor

Giao diện kéo-thả trực quan để đặt vị trí nút phát audio trên từng trang sách. Áp dụng cho tất cả trang, trang chẵn/lẻ, bật/tắt audio từng trang.

Drag & Drop Resize Apply All/Odd/Even
⚙️

Thiết lập Prompt mặc định

Cấu hình System & User Prompt mặc định cho OCR và Dịch thuật. Chọn thư mục template multimedia. Lưu localStorage, tự động load khi tạo dự án.

Settings LocalStorage Templates
🔄

Cập nhật ứng dụng

Kiểm tra cập nhật từ GitHub Releases (private repo), tải với thanh tiến trình, cài đặt ngay hoặc khi thoát. Giải nén ZIP tự động.

GitHub Releases Progress Bar Auto Install
🌓

Light / Dark Mode

Chuyển đổi giao diện sáng/tối bằng một click. Theme được lưu localStorage, tự động khôi phục khi mở lại.

Theme Toggle CSS Variables Persistent
🤖

Queue Worker tự động

Hệ thống hàng đợi: dự án "Pending" được xử lý lần lượt. Worker tự động tìm việc tiếp theo. Hỗ trợ resume nếu gián đoạn.

Auto Queue Resume Error Recovery

Chi tiết tính năng

Trải nghiệm từng tính năng

Ảnh chụp màn hình minh họa cho từng chức năng chính của ứng dụng.

📋 Tính năng 01

Quản lý dự án (Project Manager)

Giao diện quản lý dự án trực quan với bảng dữ liệu đầy đủ thông tin.

  • ✓ Danh sách dự án với phân trang (20/50/100 dòng)
  • ✓ Hiển thị tên, số trang, tài liệu, thể loại, tiến trình, trạng thái
  • ✓ 4 trạng thái: Chờ xử lý, Đang xử lý, Hoàn thành, Lỗi
  • ✓ Thanh tiến trình cập nhật real-time qua Tauri Events
  • ✓ Thao tác: Tạo mới, Xem chi tiết, Chỉnh sửa, Xóa, Xem kết quả
  • ✓ Modal xem chi tiết với đầy đủ cấu hình dự án
Project Manager — Danh sách dự án
➕ Tính năng 02

Tạo / Chỉnh sửa dự án

Form tạo dự án với đầy đủ tùy chọn xử lý.

  • ✓ Nhập tên dự án, chọn thể loại (Văn học / Khoa học)
  • ✓ Checkbox nội dung: Công thức, Latex, Hình ảnh, Bảng, Footnote
  • ✓ Chọn file PDF/DOCX — tự động đếm số trang PDF
  • ✓ Toggle: Gộp file, Trang đôi, OCR, Dịch, Multimedia, Audio
  • ✓ Chỉnh sửa Prompt cho OCR và Dịch riêng biệt
  • ✓ Chọn trạng thái: Chờ đợi hoặc Xếp hàng (auto-process)
Create Project — Form tạo dự án
🔍 Tính năng 03

OCR & Dịch thuật AI

Pipeline xử lý tự động với tiến trình real-time.

  • ✓ Render PDF thành ảnh 1200px bằng pdfium (Rust native)
  • ✓ OCR song song 5 trang bằng Gemini Vision API
  • ✓ Lưu kết quả từng trang vào file DOCX riêng lẻ
  • ✓ Dịch với context 2 đoạn trước để giữ nhất quán
  • ✓ Chau chuốt đa luồng — so sánh gốc vs dịch
  • ✓ Resume tự động: tiếp tục từ segment chưa xử lý
Processing — OCR & Dịch đang chạy
📖 Tính năng 04

Xem & Chỉnh sửa kết quả

Giao diện 3 cột mạnh mẽ cho việc review và chỉnh sửa bản dịch.

  • ✓ Cột trái: Bản gốc (chỉ đọc)
  • ✓ Cột giữa: Bản dịch (có thể ẩn/hiện)
  • ✓ Cột phải: Bản chau chuốt (chỉnh sửa được)
  • ✓ Điều hướng: Trước/Sau, nhảy trang, trang đầu/cuối
  • ✓ Lưu thay đổi vào JSON, Export ra DOCX
  • ✓ Hiển thị "có thay đổi chưa lưu"
View Result — So sánh 3 bản
📚 Tính năng 05

Sách Multimedia & Audio Editor

Tạo sách lật trang HTML với tìm kiếm text và audio tích hợp.

  • ✓ Copy template → Render ảnh mobile + thumbnail
  • ✓ Trích xuất vị trí text từ PDF cho tìm kiếm
  • ✓ Chèn meta tags (OG, title) vào index.html
  • ✓ Cập nhật config.js: totalPageCount, largePageHeight
  • ✓ Audio Editor: cửa sổ riêng, kéo-thả vùng audio
  • ✓ Áp dụng vị trí cho tất cả / trang chẵn / trang lẻ
Audio Editor — Kéo thả vị trí 🔊

Thiết lập & Cập nhật

Cài đặt & Phát triển

Hướng dẫn cài đặt môi trường phát triển.

Yêu cầu hệ thống

Cài đặt Node.js, pnpm, Rust và Tauri prerequisites.

Clone repository

git clone https://github.com/hoangduchai182/deeptransai-tauri.git

Cài đặt dependencies

pnpm install — cài đặt tất cả packages frontend.

Chạy ở chế độ phát triển

pnpm tauri dev — khởi động Vite dev server + compile Rust backend.

Build sản phẩm

pnpm tauri build — tạo file cài đặt (.msi / .exe) cho Windows.
